# 노가정 관리자 앱 사용 안내

## Windows

`artifacts/desktop/Nogajeng-Manager-1.0.0.exe`를 실행합니다. 별도 설치 없이 실행되는 Windows x64 앱입니다.
1. 관리자 비밀번호로 로그인합니다.
2. 알림음 20종 중 선택하거나 10MB 이하 MP3/WAV를 등록합니다.
3. 소리 테스트로 Windows 미디어 음량을 확인합니다.
4. 알림 켜기를 누릅니다. 15초마다 새 예약을 확인합니다.
5. 새 미확인 예약이 있으면 소리가 계속 반복됩니다. '현재 알림 확인' 또는 트레이의 '알림 확인'으로 멈춥니다. 예약 확정은 별도입니다.
6. 창 닫기(X)는 트레이로 숨깁니다. 완전히 종료하려면 트레이 메뉴 '앱 완전히 종료'를 선택합니다.

선택 음원과 확인 기록은 이 PC에 저장됩니다. 다른 기기로 자동 복사되지 않습니다. PC 전원 꺼짐·절전·네트워크 끊김·세션 만료 때는 새 예약 감지가 불가능합니다. 현재 로그인 세션은 8시간이며 만료 후 재로그인이 필요합니다. 자동 시작은 등록하지 않았습니다. Windows 배포 파일은 코드 서명 인증서를 적용하지 않은 빌드입니다.

## Android

앱 프로젝트: `apps/mobile`. 앱 ID: `net.helionlife.nogajeng.manager`.
현재 화면을 연 상태에서 예약 관리와 소리 설정을 사용하는 검증용 버전입니다. 앱이 닫힌 상태의 푸시는 아직 연결되지 않았습니다. APK 설치만으로 백그라운드 푸시가 활성화되지는 않습니다.

## Firebase 연결에 필요한 단계

1. https://console.firebase.google.com/ 에서 Google 계정으로 로그인합니다.
2. 새 프로젝트를 만듭니다. 프로젝트 표시 이름은 '노가정 예약 관리'로 입력하면 됩니다. Analytics는 이 기능에 필수가 아닙니다.
3. 프로젝트에서 Android 앱 추가를 선택합니다.
4. Android 패키지 이름에 `net.helionlife.nogajeng.manager`를 정확히 입력합니다.
5. google-services.json을 내려받아 `apps/mobile/android/app/google-services.json`에 저장합니다. 이 파일은 Git에서 제외됩니다.
6. 프로젝트 설정의 서비스 계정에서 서버 발송 인증을 구성해야 합니다. 서비스 계정 비공개 키는 채팅이나 Git에 붙이지 말고 .private 아래에 보관한 뒤 서버 환경변수로 설정합니다.

프로젝트 연결 후 남은 개발: 기기별 FCM 토큰 등록·폐기, 관리자 인증을 거친 구독 관리, 예약 생성 후 서버 푸시 발송 및 실패 재시도, 로그아웃 시 구독 해제, 실제 Android 기기의 화면 꺼짐·재부팅·절전 상태 검증. Android 잠금 화면 푸시와 PC 반복 음악은 운영체제 동작이 다르며, 무조건 수신을 보장할 수 없습니다.

## 검증

`node check-alerts.cjs`: 실제 예약을 건드리지 않고 알림음 20종, 반복, 확인, 새 알림, 음소거, WAV 저장·재실행·삭제, 모바일 너비 확인.
`node check-desktop.cjs`: Electron 앱 창 닫기 후 트레이 유지, 반복 알림 상태, 트레이 확인 검증.
실제 스피커 출력 음량과 Android 실제 기기 검증은 사용 기기에서 '소리 테스트'로 확인해야 합니다.
